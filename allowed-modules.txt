# Every module the released clerk-protect binary may link, one module path per
# line. `make guard` and
# TestReleaseBinaries_containNoForbiddenTermsAndLinkOnlyReviewedModules compare
# `go version -m` on the built binary against this file and fail on anything
# else.
#
# WHY A LIST OF WHAT SHIPS, NOT OF WHAT IS IMPORTED. This binary is published.
# Its dependency closure is what a customer runs and what a reader of the
# binary can see, and a transitive dependency arrives without anyone writing an
# import for it. Adding a line here is a review decision about a public
# artifact: say in the pull request what the module is and why it is needed.
#
# Versions are not pinned here — go.sum pins them. This file answers "may this
# module ship at all".
